## この手順書のゴール

10/18の終わりに、**全員が次の3つをできている状態**にします。これ以外のことはやりません。

1. 自分のPCで `python app.py` を実行し、ブラウザに文字が表示される
2. GitHubのリポジトリを自分のPCにコピー（clone）できている
3. 自分が書いた変更をGitHubに送れる（push）

アプリの中身を作るのは10/21以降です。今日は**器を用意するだけ**です。

> **用語について**: 「ターミナル」「コマンドプロンプト」という黒い画面に文字を打ち込む作業が出てきます。初めてだと身構えますが、やることは**この手順書の文字をコピーして貼り付け、Enterを押す**だけです。自分で考えて打つ必要はありません。

## 1. Python をインストールする

### 1-1. ダウンロード

1. ブラウザで `https://www.python.org/downloads/` を開く
2. 「Download Python 3.x.x」という黄色いボタンを押す（3.12以上であれば最新版で構いません）
3. ダウンロードされた `python-3.x.x-amd64.exe` を**ダブルクリック**

### 1-2. インストール（ここが最重要）

インストーラーの最初の画面で、**下のほうにある2つのチェックボックスに必ずチェックを入れてください。**

```
[✓] Use admin privileges when installing py.exe
[✓] Add python.exe to PATH        ← これを忘れると後の手順が全部失敗します
```

> **なぜ重要か**: 「PATHに追加」は、黒い画面で `python` と打ったときにWindowsがPythonを見つけられるようにする設定です。ここにチェックを入れ忘れると、「`python` は、内部コマンドまたは外部コマンド…として認識されていません」というエラーが出続けます。**チェックを入れ忘れた場合の対処は8章にあります。**

チェックを入れたら「**Install Now**」を押します。終わったら「Close」で閉じてください。

### 1-3. 入ったか確認する

1. キーボードの **Windowsキー** を押す
2. `cmd` と入力し、表示された「**コマンドプロンプト**」を開く
3. 黒い画面が開くので、次の1行をコピーして貼り付け、**Enter**を押す

```
py --version
```

4. こう表示されれば成功です（数字は違っても構いません）

```
Python 3.13.2
```

**エラーが出た場合は8章を見てください。** 次に進まないでください。

## 2. Visual Studio Code をインストールする

コードを書くためのソフトです。

### 2-1. ダウンロードとインストール

1. `https://code.visualstudio.com/` を開き、「Download for Windows」を押す
2. ダウンロードされたファイルをダブルクリック
3. 使用許諾に同意し、あとは「次へ」で進める
4. 途中の「追加タスクの選択」で、次の2つにチェックを入れておくと後が楽です

```
[✓] エクスプローラーのファイル コンテキスト メニューに [Code で開く] アクションを追加する
[✓] エクスプローラーのディレクトリ コンテキスト メニューに [Code で開く] アクションを追加する
```

### 2-2. 日本語化する

1. VS Codeを起動する
2. 左端のアイコンの列（アクティビティバー）から、**四角が4つ並んだアイコン**（拡張機能）を押す
3. 検索欄に `Japanese` と入力
4. 「**Japanese Language Pack for Visual Studio Code**」の「Install」を押す
5. 右下に再起動を促すボタンが出るので押す → 日本語になります

### 2-3. Python拡張機能を入れる

同じ拡張機能の画面で、

1. 検索欄に `Python` と入力
2. Microsoft製の「**Python**」（作者が `ms-python`）の「インストール」を押す

### 2-4. ターミナルをコマンドプロンプトに変更する（重要）

VS Codeの中の黒い画面は、初期設定では「PowerShell」になっています。**PowerShellのままだと6章で必ずエラーが出る**ため、先に変更しておきます。

1. `Ctrl` + `Shift` + `P` を押す（コマンドパレットが開く）
2. `terminal select default` と入力
3. 「**Terminal: Select Default Profile**」を選ぶ
4. 一覧から「**Command Prompt**」を選ぶ

これで完了です。

## 3. Git をインストールする

複数人で同じコードを扱うための道具です。

### 3-1. ダウンロードとインストール

1. `https://git-scm.com/download/win` を開く
2. 「**64-bit Git for Windows Setup**」を押す
3. ダウンロードされたファイルをダブルクリック
4. **設定項目がたくさん出ますが、すべて初期値のまま「Next」で進めて構いません。** 最後に「Install」を押します

### 3-2. 入ったか確認する

コマンドプロンプトを開き（Windowsキー → `cmd`）、

```
git --version
```

`git version 2.xx.x.windows.1` のように出れば成功です。

### 3-3. 初期設定（4行。全員必須）

誰が変更したかを記録するための設定です。**コマンドプロンプトに1行ずつ貼り付けてEnter**を押してください。2行目・3行目は自分のものに書き換えます。

```
git config --global user.name "Nakamura"
```

```
git config --global user.email "自分のメールアドレス"
```

```
git config --global core.autocrlf true
```

```
git config --global init.defaultBranch main
```

> **3行目は何をしているのか**: WindowsとLinuxでは「改行」の扱い方が違います。この設定をしておかないと、**中身を1文字も変えていないのにファイル全体が書き換わったように見える**という現象が起きます。実際にこのプロジェクトの企画書で、改行の扱いを間違えて表が崩れる事故が起きています。必ず実行してください。

設定できたか確認する場合は次の1行です。

```
git config --global --list
```

## 5. リポジトリを自分のPCにコピーする（clone）

### 5-1. 置き場所を決める

ここではデスクトップに置きます。clone すると、デスクトップに `lifestyle-habits` というフォルダが自動で作られます。

> **フォルダ名はリポジトリ名と同じ `lifestyle-habits` になります。`program` ではありません。**

コマンドプロンプトを開き、次の1行を貼り付けてEnter。

```
cd %USERPROFILE%\Desktop
```

### 5-2. clone する

次の1行を貼り付けてEnter。

```
git clone https://github.com/Okada-stu/lifestyle-habits.git
```

初回は、ブラウザが開いてGitHubへのログインを求められます。画面の指示に従ってログインしてください（2回目以降は聞かれません）。

### 5-3. 確認

```
cd lifestyle-habits
```

```
dir
```

`docs`、`app.py`、`requirements.txt`、`.gitignore` などが表示されれば成功です。

### 5-4. VS Code で開く

```
code .
```

VS Codeが起動し、左側にファイルの一覧が出ます。最後の `.`（ピリオド）を忘れないでください。

## 6. 仮想環境とライブラリを用意する

ここから先は**VS Code の中のターミナル**で作業します。

VS Codeで `Ctrl` + `@`（または上部メニューの「ターミナル」→「新しいターミナル」）を押してください。画面の下半分に黒い画面が出ます。

左下に `C:\Users\...\lifestyle-habits>` のように表示されていることを確認してください。`PS C:\...` と表示されている場合は、2-4のターミナル変更ができていません。戻ってやり直してください。

### 6-1. 仮想環境を作る

```
py -m venv .venv
```

何も表示されずに終わりますが、それで正常です。30秒ほどかかります。

> **仮想環境とは**: このプロジェクト専用のPython置き場です。プロジェクトごとに必要なライブラリは違うので、PC全体に入れるのではなく、フォルダの中に閉じ込めます。`lifestyle-habits` フォルダの中に `.venv` というフォルダができています（`.gitignore` 済みなのでGitHubには送られません）。

### 6-2. 仮想環境を有効にする

```
.venv\Scripts\activate
```

成功すると、行の先頭に `(.venv)` が付きます。

```
(.venv) C:\Users\nakamura\Desktop\lifestyle-habits>
```

> **この `(.venv)` は、ターミナルを開き直すたびに消えます。** 作業を始めるときは毎回このコマンドを実行してください。付いていない状態でライブラリを入れたり実行したりすると、動かない原因になります。

### 6-3. ライブラリを入れる

```
pip install -r requirements.txt
```

1〜3分かかります。最後に `Successfully installed ...` と出れば成功です。

> **`requirements.txt` とは**: このプロジェクトに必要なライブラリを、**バージョンを固定して**書いた一覧です。4人が同じ版を使うためのファイルで、リポジトリに既に入っています。
>
> **このファイルを `pip freeze > requirements.txt` で上書きしないでください。** 手書きのコメントとバージョン指定が消え、他の3人の環境が壊れます。ライブラリを追加したいときは、先にDiscordで相談してください（`docs/04` 5章）。

### 6-4. `.env` を作る

Discordのwebhook URLのような秘密情報は、コードにもGitにも入れず `.env` というファイルに書きます。**このファイルは `git clone` では来ません。** 各自が作ります。

```
copy .env.example .env
```

作成した `.env` をVS Codeで開き、次の3つを埋めてください。

| キー                   | 入れる値                                               |
| ---------------------- | ------------------------------------------------------ |
| `DISCORD_WEBHOOK_URL`  | オオイシさんがDiscordで共有します                      |
| `SECRET_KEY`           | 各自が適当な長い文字列を入れます（共有しません）       |
| `MY_USER_ID`           | `abe` / `oishi` / `okada` / `nakamura` のうち自分のもの |

> **`.env` は絶対にGitHubに送らないでください。** webhook URLが分かれば誰でもDiscordに投稿できてしまいます。`.gitignore` で除外済みなので普通に作業していれば送られませんが、VS Codeのファイル一覧で `.env` が**グレー表示**になっていることを確認してください。それが除外されている証拠です。

## 7. 動くか確認する

### 7-1. ファイルを作る

1. VS Codeの左側のファイル一覧の空白を右クリック → 「新しいファイル」
2. ファイル名を `hello.py` にする
3. 開いたファイルに次の内容を貼り付け、`Ctrl` + `S` で保存

```python
from flask import Flask

app = Flask(__name__)


@app.route("/")
def index():
    return "<h1>環境構築できました</h1><p>Flask が動いています。</p>"


if __name__ == "__main__":
    app.run(debug=True)
```

### 7-2. 実行する

ターミナル（`(.venv)` が付いている状態）で、

```
py hello.py
```

次のような表示が出ます。

```
 * Running on http://127.0.0.1:5000
 * Restarting with stat
 * Debugger is active!
```

**Windowsのセキュリティ警告（ファイアウォール）が出た場合は「アクセスを許可する」を押してください。**

### 7-3. ブラウザで見る

ブラウザのアドレス欄に次を入力してEnter。

```
http://127.0.0.1:5000
```

「**環境構築できました**」と表示されれば、**この手順書の目的は達成です。**

### 7-4. 止める

ターミナルをクリックして、`Ctrl` + `C` を押します。これでアプリが止まります。

> **いま何が起きていたのか**: `py hello.py` を実行している間、**自分のPCが一時的にWebサーバーになっています**。`127.0.0.1` は「自分自身」を指す住所で、外部とは一切通信していません。だから他の人からは見えません。他の人からも見えるようにするのが第2段階（EC2へのデプロイ）で、そこはオカダが担当します。

## 8. Git の使い方（最低限の5つ）

全員Gitが初めてなので、**使うコマンドは5つだけ**に絞ります。これ以外は使わないでください。

### 作業を始めるとき

```
git pull
```

他の人の変更を自分のPCに取り込みます。**作業開始時に必ず最初に実行してください。** これを忘れると、後で衝突して面倒になります。

### 自分の作業用の場所を作る（初回だけ）

```
git switch -c nakamura
```

`nakamura` の部分は自分の名前にします。これは「ブランチ」を作る操作で、**自分の作業を本体（`main`）と分けておくため**です。他の人の作業を壊す心配なく進められます。

2回目以降、自分の場所に戻るときは `-c` を外します。

```
git switch nakamura
```

### 変更を記録するとき（1日の終わりなど）

```
git add .
```

```
git commit -m "入力画面のフォームを作成"
```

`-m` の後ろには、**何をしたかを日本語で短く**書きます。「修正」「更新」だけだと後から見て分からないので避けてください。

### GitHubに送るとき

```
git push -u origin nakamura
```

`nakamura` は自分のブランチ名です。2回目以降は `git push` だけで済みます。

---

**本体（`main`）への取り込みは、相談の場（水・日）で全員で確認してから行います。** 各自でやらないでください。企画書12章の相互レビューは、このタイミングで行います。

| やること           | コマンド                              |
| ------------------ | ------------------------------------- |
| 作業開始時         | `git pull`                          |
| 自分の場所へ移動   | `git switch 自分の名前`             |
| 変更を記録         | `git add .` → `git commit -m "..."` |
| GitHubへ送る       | `git push`                          |
| 本体への取り込み   | 相談の場で全員で行う（各自やらない）  |

## 9. つまずいたときの対処

### `python` または `py` が認識されていません

```
'py' は、内部コマンドまたは外部コマンド、操作可能なプログラム
またはバッチ ファイルとして認識されていません。
```

1-2の「**Add python.exe to PATH**」のチェックを忘れています。

**対処**: もう一度インストーラー（`python-3.x.x-amd64.exe`）を実行し、「**Modify**」ではなく一度「**Uninstall**」してから、チェックを入れて入れ直すのが確実です。入れ直した後、**コマンドプロンプトを開き直してから**確認してください（開いたままでは反映されません）。

### `.venv\Scripts\activate` でエラーが出る

```
このシステムではスクリプトの実行が無効になっているため…
```

ターミナルがPowerShellになっています。2-4の手順でコマンドプロンプトに変更し、**ターミナルを閉じて開き直してから**やり直してください。

どうしてもPowerShellで進めたい場合は、次の1行を実行してから再度 activate します。

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### `pip` は認識されているが、入れたライブラリが見つからない

```
ModuleNotFoundError: No module named 'flask'
```

行の先頭に `(.venv)` が付いていない状態で実行しています。6-2 を実行してから、もう一度試してください。

### ポート5000が使われている

```
OSError: [WinError 10048] 通常、各ソケット アドレスに対して…
```

前に起動したアプリが止まっていません。すべてのターミナルで `Ctrl` + `C` を押すか、VS Codeを再起動してください。

### ブラウザに何も表示されない

- アドレスが `http://127.0.0.1:5000` になっているか（`https` ではありません）
- ターミナルに `Running on http://127.0.0.1:5000` が出ているか
- `Ctrl` + `C` で止めてしまっていないか

### `git clone` でパスワードを聞かれて先に進めない

GitHubは2021年からパスワード認証を廃止しています。ブラウザが開いてログインする形になるので、**ブラウザ側の画面を確認してください**（別ウィンドウの裏に隠れていることがあります）。

### 上記で解決しない場合

**自分でAIと格闘せず、オカダに連絡してください。** エラーの赤い文字を**全文コピーして**貼ってください。一部だけだと原因が特定できません。
